Basic & Chunk return the whole file in one response (identical display; they differ server-side — buffered vs. streamed 64 KB at a time, Content-Length vs. Transfer-Encoding: chunked). HTTP Range instead runs an init request for the total size, then pulls the file in Range: bytes=start-end windows — each answered 206 Partial Content — and stitches them back together. All three now take fileName/uploadType as query params.
