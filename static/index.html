Basic

Raw body. Server buffers the whole file in memory.

POST /video/basic/upload/v1

Multipart

multipart/form-data with the file part + filename.

POST /video/multipart/upload/v1

Stream

Raw body, streamed to disk server-side.

POST /video/stream/upload/v1

Multipart Stream

multipart/form-data, streamed field-by-field to disk server-side.

POST /video/multipart/stream/upload/v1

Chunked (waiting)

Inits a transfer with totalChunks + contentType to get an uploadId, then sends raw binary chunks sequentially with just the chunkIndex query param.

POST /video/chunked/init/upload/v1 → /video/chunked/upload

Resumable

Remembers the uploadId in localStorage, asks the server which chunks it already has, and sends only the missing ones. The Upload button becomes Pause mid-transfer — hit it to stop, then Resume to pick up where you left off.

POST init → GET status → POST /video/resumable/upload/v1
